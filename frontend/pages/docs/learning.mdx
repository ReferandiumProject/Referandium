## Token Locking Mechanics

### How Locking Works

**Smart contract flow:**

```rust
1. User approves RFRM transfer
2. Contract calculates required lock amount ($25 equivalent)
3. Tokens transferred to program-owned account
4. User marked as "active subscriber" in contract state
5. Frontend checks on-chain status before granting access
6. User retains ownership, cannot transfer
7. Cancel → Tokens returned to wallet
```

### Lock Duration

**Flexible options:**
- No minimum lock period
- Pay monthly equivalents upfront if desired
- Lock for 12 months → Get 2 months free (17% discount)
- Automatic monthly renewal (requires approval)

**Example: 3-month prepay**
```
Lock: 750 RFRM (3 × 250)
Access: 3 months
Unlock: After 90 days or cancel early (pro-rated refund)
```

### Cancellation & Refunds

**Cancel anytime:**
- Unlock remaining RFRM balance
- Pro-rated refund if prepaid multiple months
- No penalty fees
- Access removed immediately

**Refund calculation:**
```
Refund = Total Locked × (Days Remaining ÷ Total Days)

Example:
Locked: 750 RFRM (3 months = 90 days)
Elapsed: 30 days
Remaining: 60 days
Refund: 750 × (60 ÷ 90) = 500 RFRM
```

## FAQ

### Is my RFRM locked forever?

No. You can cancel and unlock your RFRM anytime. There are no penalties.

### What if RFRM price crashes while I'm subscribed?

You locked a dollar amount ($25), not a token amount. When you cancel, you get back the same number of tokens you locked, regardless of current price.

### What if RFRM price moons while I'm subscribed?

Same answer - you get back the exact tokens you locked. The dollar value may have changed, but token amount is fixed.

### Can I gift subscriptions?

Not yet, but planned for Q2 2026. You'll be able to lock tokens on behalf of another wallet address.
